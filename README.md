# Beecrowd 1038 - Lanche



## Descrição



Este programa resolve o problema 1038 do Beecrowd.



## Tecnologias utilizadas



- Java

- NetBeans

- Maven



## Entrada



A entrada contém dois valores inteiros: o código do produto e a quantidade comprada.



## Saída



O programa apresenta o valor total da compra no formato:



**Total: R$ resultado**
